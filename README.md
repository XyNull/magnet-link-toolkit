# 磁力链增强工具箱（magnet-link-toolkit）

一个 Tampermonkey / 油猴用户脚本，为磁力搜索站点提供**一键复制磁力链**、**累积队列复制**、**批量推送到 115 离线**与 **qBittorrent** 等能力。

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等兼容脚本管理器）。
2. 打开下面的链接即可安装 / 更新：
   ```
   https://raw.githubusercontent.com/XyNull/magnet-link-toolkit/main/magnet-link-toolkit.user.js
   ```
   （Tampermonkey 会自动识别 `.user.js` 并弹出安装页）

## 使用

### 每个资源条目旁的按钮组

| 按钮 | 作用 |
| --- | --- |
| 📋 复制 | 复制该条磁力链，同时加入累积队列 |
| 115 | 把该条磁力链推送到 115 网盘离线下载（需已登录 115 会员账号） |
| qB | 把该条磁力链推送到 qBittorrent（需先在设置中配置 WebUI） |
| 🌐 打开 | 用默认磁力工具打开该磁力链 |

按钮顺序可在「设置 → 按钮显示」中拖拽调整，也可单独关闭某个按钮。

### 左下角 4 个悬浮按钮

| 按钮 | 单击 | 其他操作 |
| --- | --- | --- |
| ⚙️ 设置 | 打开设置面板 | 可拖动 |
| 📋 复制全部 | 收集并复制当前页全部磁力链，同时加入队列 | 可拖动 |
| ☰ 队列 | 把队列中全部磁力链复制到剪贴板（换行分隔）后清空 | 双击清空队列；可拖动 |
| qB 推送 | 把队列中全部磁力链批量推送到 qBittorrent，成功后清空队列 | 可拖动 |

> 队列按钮上的红色数字徽标表示当前累积条数。
> 悬浮按钮是否可拖动由「设置 → 按钮显示 → 悬浮按钮 → 允许拖动悬浮按钮」控制；下方还有「重置悬浮按钮位置」。

### 菜单命令（Tampermonkey 面板）

- 打开设置面板
- 检查 115 登录状态 / 打开 115 网盘
- 复制当前页全部磁力链
- 复制累积队列全部磁力链 / 清空累积队列

- 推送本页全部 torrent 到 qBittorrent（ExHentai）

## ExHentai / E-Hentai：.torrent 推送到 qBittorrent

ExHentai 不提供磁力链，只提供 `.torrent` 种子文件（`https://exhentai.org/torrent/{gid}/{hash}/{infohash}.torrent`）。

推送方式与磁力链完全一致：把该 URL 塞进 qB 的 `urls` 参数，**由 qB 自己去下载种子**。
所以唯一的前提是 **qB 所在机器能访问 exhentai.org / e-hentai.org** —— 在 qB 里配好代理即可
（qB 的「选项 → 连接 → 代理服务器」，或用透明代理 / 分流）。

| 位置 | 操作 |
| --- | --- |
| `torrents.php` 列表页 / `gallerytorrents.php` 弹窗页 | 每个 `.torrent` 链接右侧出现蓝色小图标，点击即把该种子链接推给 qB |
| 画廊列表页 / 画廊详情页的 `T` 图标 | 旁边多一个小图标，点击会先抓取该画廊的种子列表，再把链接批量推给 qB（多个种子时会确认） |
| 菜单命令 | 「推送本页全部 torrent 到 qBittorrent」：当前页有直链则直接推；没有则逐个画廊反查后合并成**一次** `urls` 请求推送 |

推送时会带上「设置 → qBittorrent」里配置的保存路径 / 分类 / 标签 / 推送后暂停，与原磁力链推送共用同一套配置。

> 站点开关里新增了 **ExHentai(种子→qB)**，可单独关掉。
> 浏览器侧只负责「解析出种子链接」，不下载种子本体，所以几乎无流量开销；
> 整页批量反查会依次请求每个画廊（间隔 0.6 秒），页面上画廊较多时请耐心等待，过快可能触发站点限流。

> 提示：如果 qB 已能访问站点，直接在 `torrents.php` 页面用（那里每行都有种子直链），比在画廊列表页逐个反查更快。

## 配置

### 115 离线推送

需要在浏览器中登录 115 会员账号（脚本会复用浏览器会话）。可在「设置 → 115 网盘」中检查登录状态。

### qBittorrent 推送

前提：qBittorrent 已开启 WebUI ——「选项 → Web UI」勾选 **Web 用户界面（远程控制）**，并记下端口（默认 `8080`）。

在「设置 → qBittorrent」中填写：

| 配置项 | 说明 |
| --- | --- |
| WebUI 地址 | 如 `http://127.0.0.1:8080`（不带协议会自动补 `http://`） |
| 用户名 / 密码 | 默认账号为 `admin`；若已勾选“对本机免密登录”可留空，脚本会直接复用浏览器已有会话 |
| 保存路径 | 可选，不填则用 qB 默认下载目录 |
| 分类 / 标签 | 可选，推送时自动归类、打标签 |
| 推送后暂停任务 | 可选，便于批量审核后再开始下载 |
| 测试连接 | 一键验证地址与账号是否可用（会显示 qB 版本号） |

> 若 qB 开启了「启用 Host header 验证」或使用了反向代理，请把 WebUI 地址填成实际访问地址。

## 支持的站点

BT4G、BTDigg、BTSOW、Nyaa、動漫花園（DMHY）、观影、SeedHub、梦幻天堂·龙网（LongWangBT）、雨花阁（YuHuaGe）、SOBT、CLB（磁力宝）、BT目录（BTMulu）、ØMagnet（无极磁链）、磁力帝、ExHentai / E-Hentai 等。

## 常见问题

**Q：复制全部时有些条目没抓到磁力链？**
A：BT4G、SeedHub 等站点的磁力链需要访问详情页才能拿到，脚本会并发抓取（限流 4 路、单请求 8 秒超时）。若站点风控或网络较慢导致个别失败，通知里会提示失败条数，可稍后重试或点击该条目旁的复制按钮单独获取。

**Q：qB 推送提示 403 / 401？**
A：401 通常是用户名或密码错误；403 可能是密码连续错误导致 qB 临时封禁（等待数分钟），或 IP 被限制。请先用「测试连接」确认。

**Q：队列数据存在哪里？**
A：保存在脚本管理器（Tampermonkey）的存储中，因此刷新页面、切换站点都不会丢；上限 300 条并自动去重。

**Q：qBittorrent 在另一台机器上，地址怎么填？**
A：填局域网可达的完整地址，例如 `http://192.168.1.20:8080`。若 qB 勾选了「对本机免密登录」，只有本机能免密，跨机器仍需在设置里填用户名密码；填完用「测试连接」确认。

**Q：ExHentai 推送成功但 qB 里没有任务 / 提示 415？**
A：多半是 qB 所在机器访问不到站点，或没走代理。qB 添加种子后会自己去下载那个 URL，拉不到就会失败。请先在 qB 机器上用浏览器打开一次 `.torrent` 链接确认能下载，再回去检查 qB 的代理设置。

**Q：ExHentai 整页批量时提示抓取失败？**
A：站点对短时间内的连续请求会临时限流。脚本已按 0.6 秒间隔串行请求，若仍失败，减少单页画廊数量或稍后再试。
