# 磁力链增强工具箱（magnet-link-toolkit）

一个 Tampermonkey / 油猴用户脚本，为磁力搜索站点提供**一键复制磁力链**、**累积队列复制**、**批量推送到 115 离线**与 **qBittorrent** 等能力。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey 等兼容脚本管理器）。
2. 打开下面的链接即可安装 / 更新：
   ```
   https://raw.githubusercontent.com/XyNull/magnet-link-toolkit/main/magnet-link-toolkit.user.js
   ```
   （Tampermonkey 会自动识别 `.user.js` 并弹出安装页）

## 使用

### 每个资源条目旁的按钮组

| 按钮 | 作用 |
| --- | --- |
| 📋 复制 | 复制该条磁力链，同时加入累积队列 |
| 115 | 把该条磁力链推送到 115 网盘离线下载（需已登录 115 会员账号） |
| qB | 把该条磁力链推送到 qBittorrent（需先在设置中配置 WebUI） |
| 🌐 打开 | 用默认磁力工具打开该磁力链 |

按钮顺序可在「设置 → 按钮显示」中拖拽调整，也可单独关闭某个按钮。

### 左下角 4 个悬浮按钮

| 按钮 | 单击 | 其他操作 |
| --- | --- | --- |
| ⚙️ 设置 | 打开设置面板 | 可拖动 |
| 📋 复制全部 | 收集并复制当前页全部磁力链，同时加入队列 | 可拖动 |
| ☰ 队列 | 把队列中全部磁力链复制到剪贴板（换行分隔）后清空 | 双击清空队列；可拖动 |
| qB 推送 | 把队列中全部磁力链批量推送到 qBittorrent，成功后清空队列 | 可拖动 |

> 队列按钮上的红色数字徽标表示当前累积条数。
> 悬浮按钮是否可拖动由「设置 → 按钮显示 → 悬浮按钮 → 允许拖动悬浮按钮」控制；下方还有「重置悬浮按钮位置」。

### 菜单命令（Tampermonkey 面板）

- 打开设置面板
- 检查 115 登录状态 / 打开 115 网盘
- 复制当前页全部磁力链
- 复制累积队列全部磁力链 / 清空累积队列
- 推送累积队列到 qBittorrent / 测试 qBittorrent 连接

## 配置

### 115 离线推送

需要在浏览器中登录 115 会员账号（脚本会复用浏览器会话）。可在「设置 → 115 网盘」中检查登录状态。

### qBittorrent 推送

前提：qBittorrent 已开启 WebUI ——「选项 → Web UI」勾选 **Web 用户界面（远程控制）**，并记下端口（默认 `8080`）。

在「设置 → qBittorrent」中填写：

| 配置项 | 说明 |
| --- | --- |
| WebUI 地址 | 如 `http://127.0.0.1:8080`（不带协议会自动补 `http://`） |
| 用户名 / 密码 | 默认账号为 `admin`；若已勾选“对本机免密登录”可留空，脚本会直接复用浏览器已有会话 |
| 保存路径 | 可选，不填则用 qB 默认下载目录 |
| 分类 / 标签 | 可选，推送时自动归类、打标签 |
| 推送后暂停任务 | 可选，便于批量审核后再开始下载 |
| 测试连接 | 一键验证地址与账号是否可用（会显示 qB 版本号） |

> 若 qB 开启了「启用 Host header 验证」或使用了反向代理，请把 WebUI 地址填成实际访问地址。

## 支持的站点

BT4G、BTDigg、BTSOW、Nyaa、動漫花園（DMHY）、观影、SeedHub、梦幻天堂·龙网（LongWangBT）、雨花阁（YuHuaGe）、SOBT、CLB（磁力宝）、BT目录（BTMulu）、ØMagnet（无极磁链）、磁力帝 等。

站点规则可在「设置 → 站点开关」中按需启用/禁用。

## 常见问题

**Q：复制全部时有些条目没抓到磁力链？**
A：BT4G、SeedHub 等站点的磁力链需要访问详情页才能拿到，脚本会并发抓取（限流 4 路、单请求 8 秒超时）。若站点风控或网络较慢导致个别失败，通知里会提示失败条数，可稍后重试或点击该条目旁的复制按钮单独获取。

**Q：qB 推送提示 403 / 401？**
A：401 通常是用户名或密码错误；403 可能是密码连续错误导致 qB 临时封禁（等待数分钟），或 IP 被限制。请先用「测试连接」确认。

**Q：队列数据存在哪里？**
A：保存在脚本管理器（Tampermonkey）的存储中，因此刷新页面、切换站点都不会丢；上限 300 条并自动去重。
